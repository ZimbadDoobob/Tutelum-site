what you need

  • two hardware keys that support FIDO2 or WebAuthn: one primary, one backup
  • your password manager, open and unlocked
  • a list of accounts to protect, starting with:
    • your primary email
    • your password manager
    • your phone carrier or Apple, Google, or Microsoft account

steps

  1. Start with email. Whoever controls your email can usually reset every other password, so protect it first.
  2. Open the account’s security settings and look for security key, passkey, or two-step verification. The wording differs between services.
  3. Choose to add a key. When asked, insert it or tap it, then give it a name such as primary-keyring.
  4. Repeat with the second key and name it backup-safe. Store it somewhere other than your daily key.
  5. Save any recovery codes the service offers into your password manager.
  6. Test it: sign out, then sign back in using the key. Press Esc if a prompt gets stuck and try again.

using a key for ssh

If you log in to servers over SSH, you can make a key that only works while the hardware key is plugged in. This needs OpenSSH 8.2 or newer.

ssh-keygen -t ed25519-sk -C "primary-keyring"
cat ~/.ssh/id_ed25519_sk.pub

Add the printed public key to your server’s authorized_keys file, then test a login before closing your current session.

why two keys

If losing one key would lock you out, that key is a single point of failure.

key lives used for
primary on your keyring daily sign-ins
backup stored separately recovery only

how to undo it

Open each account’s security settings and remove the key. Before you do, confirm that another sign-in method still works, or you may lock yourself out.
